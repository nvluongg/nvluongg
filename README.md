### CineNote – Serverless Movie Review Web Application on AWS

A serverless movie review web application built with AWS cloud services.

**Tech stack:**
- Frontend: HTML, CSS, JavaScript, AWS Amplify Hosting
- Authentication: Amazon Cognito
- Backend: API Gateway, AWS Lambda
- Database: DynamoDB
- Infrastructure as Code: AWS CloudFormation

**Highlights:**
- Built a serverless AWS web application using Amplify, Cognito, API Gateway, Lambda, and DynamoDB
- Implemented authentication and role-based access control with Cognito User Pool and Admin group
- Developed Lambda backend APIs for movie CRUD, review management, rating aggregation, and admin moderation
- Defined cloud infrastructure using AWS CloudFormation
- Applied basic security controls such as authenticated API access, admin-only actions, input validation, and review content flagging
